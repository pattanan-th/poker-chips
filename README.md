# Kapoke Chip

เว็บนับชิปโป๊กเกอร์สำหรับเล่นกับไพ่จริง ทุกคนใช้มือถือของตัวเองกด Fold / Check / Call / Raise ได้ ไม่ต้องใช้ server และไม่ต้องสมัครบัญชี
มือถือของเจ้ามือทำหน้าที่เป็นเครื่องหลัก (WebRTC ผ่าน PeerJS) คนอื่นสแกน QR เข้าห้อง

- Texas Hold'em No-Limit: blinds/ante, ปุ่ม Dealer หมุนเอง, min-raise, side pot, split pot, คืน uncalled bet
- Omaha (Pot-Limit, PLO): เลือกในตั้งค่า → "เกม" — Raise ได้สูงสุดเท่า Pot, แอปแจกไพ่คนละ 4 ใบและตัดสินแบบ Omaha (ใช้ไพ่ในมือ 2 ใบพอดี + กลาง 3 ใบ)
- Cash game (rebuy หรือแบบไม่ต้อง buy-in ยอด +/- ไม่จำกัด, จับเวลาเล่น, สรุปใครโอนให้ใคร) หรือ Tournament (blind ขึ้นตามเวลา, จัดอันดับ)
- ไม่มีไพ่จริงก็เล่นได้: ตั้งค่า "แอปแจกไพ่ให้" — สับไพ่ด้วย crypto RNG, ส่งไพ่ให้แต่ละคนเฉพาะของตัวเอง, เปิดไพ่กลางทีละรอบ, ตัดสินผู้ชนะอัตโนมัติ
- ประวัติรายมือ 30 มือล่าสุด
- เจ้ามือ: Undo, กดแทนผู้เล่น, แก้ชิป, จัดที่นั่ง, หยุดเวลา, ส่งต่อเจ้ามือ
- เจ้ามือหลุด: ผู้เล่นกด "รับเป็นเจ้ามือแทน" เล่นต่อจาก state ล่าสุดในเครื่องตัวเอง

- **ป๊อกเด้ง**: บันทึกเดิมพันและผลแต่ละรอบเทียบกับเจ้ามือ (ชนะ/แพ้/เสมอ ×1 ×2 ×3 ×5) สรุปยอดและใครโอนให้ใคร
